# Master-s-Thesis-LP-Code

Two linear programs are provided here to (re)produce the results presented in this Master's thesis. These programs are closely related to the findings reported in the publication by Kriváchy et al. (2025), *"Closing the detection loophole in the triangle network with high-dimensional photonic states"*, available at [arXiv:2503.24213](https://doi.org/10.48550/arXiv.2503.24213).

For further details and a deeper understanding of the context, we recommend consulting the original publication.
